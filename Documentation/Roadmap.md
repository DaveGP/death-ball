# Roadmap

## Prototype

* [x] Unity 6 project with FishNet and the Input System
* [x] Character controller ported from Crewfall, with per-character input sources
* [x] Local couch multiplayer (one reader per device)
* [ ] Ball: pick up, carry, pass, shoot, loose-ball physics
* [ ] Goal rings and scoring
* [ ] Basic melee, health and knockouts
* [ ] Both win conditions (points at time, full knockout)
* [x] Teammate switching
* [x] Simple AI filling every unused slot
* [x] One grey-box arena

## Development

* [ ] Online multiplayer with mixed couch and online players
* [ ] Stamina, blocking, dodging and specials
* [ ] Player types
* [ ] Ball overcharge
* [ ] Team tactics AI
* [ ] Arena hazards and more arenas
* [ ] League mode
* [ ] Art, animation, audio and commentary
* [ ] Polishing and optimisation
