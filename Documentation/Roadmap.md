# Roadmap

## Prototype

* [x] Unity 6 project with FishNet and the Input System
* [x] Character controller ported from Crewfall, with per-character input sources
* [x] Local couch multiplayer (one reader per device)
* [x] Ball: pick up, carry, pass, shoot, loose-ball physics
* [x] Goal rings and scoring
* [x] Basic melee, health and knockouts
* [x] Both win conditions (points at time, full knockout), plus sudden death
* [x] Teammate switching
* [x] Simple AI filling every unused slot
* [x] One grey-box arena

## Development

* [x] Main menu and lobby: host or join, teams, player types, match length

* [x] Online multiplayer with mixed couch and online players (tested with two editors on one machine)
* [x] Stamina and specials (one shared special, Slam, until player types)
* [x] Player types, each with its own special
* [ ] Ball overcharge
* [x] Team tactics AI
* [x] Arena hazards: electric walls, floor vents, rising barriers
* [ ] More arenas
* [ ] League mode
* [ ] Art, animation, audio and commentary
* [ ] Polishing and optimisation
