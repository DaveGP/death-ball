# Death Ball

## Overview

**Death Ball** is a brutal, futuristic 4v4 arena sport.

Two teams fight over a single steel ball inside a sealed arena. Win by scoring more than the other team, or by putting all four of their players on the floor.

## Features

* 4v4 arena sport with full-contact combat
* Two ways to win: score goals or knock out the whole opposing team
* Swap control between teammates on the fly
* Any player slot can be local, couch multiplayer, online or AI
* League mode with injuries, team management and progression

## Getting Started

### Requirements

Before opening the project, ensure you have:

* Unity 6 installed
* Git installed
* Git LFS installed

### Installation

Clone the repository:

```bash
git clone https://github.com/DaveGP/death-ball.git
```

Install Git LFS:

```bash
git lfs install
```

Open the project using Unity Hub and select the correct Unity version.

## Controls

Press any button on a keyboard or gamepad to join. Up to 4 local players; by default they alternate between Home and Away.

| Action         | Keyboard & Mouse | Gamepad            |
| -------------- | ---------------- | ------------------ |
| Move           | WASD             | Left stick         |
| Aim            | Arrow keys       | Right stick        |
| Sprint         | Left Shift       | Left stick press   |
| Pass           | E                | A / Cross          |
| Shoot          | F (hold to charge and aim, release to fire) | Right trigger (hold to charge and aim, release to fire) |
| Attack         | Left mouse       | X / Square         |
| Heavy attack   | R                | Y / Triangle       |
| Tackle         | C                | B / Circle         |
| Block          | Right mouse      | Left trigger       |
| Dodge          | Space            | Right bumper       |
| Special        | Q                | Left bumper        |
| Switch player  | Tab              | Right stick press  |

Play it in the browser at https://davegp.github.io/death-ball/, or open `Assets/Scenes/MainMenu.unity` and press Play. Play locally (solo or couch), or host online and share the join code, pick teams and player types in the lobby, and start a match. Escape (or Select on a controller) leaves a match. You can also press Play on `Assets/Scenes/Arena.unity` to jump straight into a local match. Both scenes are generated by the **Death Ball** menu; see [Main Menu and Lobby](Documentation/MainMenu.md).
